# 📐 Документация к библиотеке geometric_lib

> **Общее описание решения**
> Библиотека `geometric_lib` представляет собой скрипты для вычисления площадей и периметров фигур.

---

## ⚙️ Описание функций с примерами вызова

### 🔵 Модуль `circle.py`

#### `area`
```python
def area(r)
```
Возвращает площадь круга по заданному радиусу.

**Параметры**
* **`r`** - радиус круга

**Возвращаемое значение**
Значение типа `float`, представляющее площадь круга.

**Пример**
```python
import circle
print(circle.area(5))
```
Вывод:
```text
78.53981633974483
```

#### `perimeter`
```python
def perimeter(r)
```
Возвращает длину окружности по заданному радиусу.

**Параметры**
* **`r`** - радиус круга

**Возвращаемое значение**
Значение типа `float`, представляющее длину окружности.

**Пример**
```python
import circle
print(circle.perimeter(5))
```
Вывод:
```text
31.41592653589793
```

### 🔺 Модуль `triangle.py`

#### `area`
```python
def area(a, h)
```
Возвращает площадь треугольника со стороной `a` и проведенной к ней высотой `h`.

**Параметры**
* **`a`** - сторона треугольника
* **`h`** - высота, проведенная к стороне `a`

**Возвращаемое значение**
Значение типа `float`, представляющее площадь треугольника.

**Пример**
```python
import triangle
print(triangle.area(4, 5))
```
Вывод:
```text
10.0
```

#### `perimeter`
```python
def perimeter(a, b, c)
```
Возвращает периметр треугольника со сторонами `a`, `b` и `c`.

**Параметры**
* **`a`** - первая сторона треугольника
* **`b`** - вторая сторона треугольника
* **`c`** - третья сторона треугольника

**Возвращаемое значение**
Значение типа `float`, представляющее периметр треугольника.

**Пример**
```python

print(triangle.perimeter(3, 4, 5))
```
Вывод:
```text

```

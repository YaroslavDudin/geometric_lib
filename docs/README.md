# Документация к библиотеке geometric_lib

## Общее описание решения
Библиотека `geometric_lib` представляет собой набор скриптов на языке Python для вычисления базовых геометрических характеристик плоских фигур. Проект позволяет легко находить площадь и периметр таких фигур, как круг, прямоугольник, квадрат и треугольник.

## Описание функций с примерами вызова

### Модуль `circle.py`
- `area(r)`: Возвращает площадь круга радиусом `r`.
  - Пример вызова: `area(5)` вернет `78.53981633974483`
- `perimeter(r)`: Возвращает длину окружности радиусом `r`.
  - Пример вызова: `perimeter(5)` вернет `31.41592653589793`

### Модуль `rectangle.py`
- `area(a, b)`: Возвращает площадь прямоугольника со сторонами `a` и `b`.
  - Пример вызова: `area(4, 5)` вернет `20`
- `perimeter(a, b)`: Возвращает периметр прямоугольника со сторонами `a` и `b`.
  - Пример вызова: `perimeter(4, 5)` вернет `18`

### Модуль `square.py`
- `area(a)`: Возвращает площадь квадрата со стороной `a`.
  - Пример вызова: `area(5)` вернет `25`
- `perimeter(a)`: Возвращает периметр квадрата со стороной `a`.
  - Пример вызова: `perimeter(5)` вернет `20`

### Модуль `triangle.py`
- `area(a, h)`: Возвращает площадь треугольника со стороной `a` и высотой `h`.
  - Пример вызова: `area(4, 5)` вернет `10.0`
- `perimeter(a, b, c)`: Возвращает периметр треугольника со сторонами `a`, `b` и `c`.
  - Пример вызова: `perimeter(3, 4, 5)` вернет `12`
